9.1 Encrypted envelope

IMPLEMENTED — VERIFIED IN SOURCE

- Layout: salt(16) + iv(12) + AES-256-GCM ciphertext and tag. [data/transfer/TransferCodec.kt:23-28,33-45]
- Salt and IV are random from SecureRandom. [TransferCodec.kt:31,35-36]
- Transformation AES/GCM/NoPadding; key 256 bits; tag 128 bits. [TransferCodec.kt:85-91]
- AAD is a fixed ASCII string applied on encrypt and decrypt; literal value deliberately not reproduced here. [TransferCodec.kt:41,58,92]
- Key derivation: PBKDF2WithHmacSHA256 over passphrase, salt concatenated with a hard-coded app-specific pepper, configured iterations, 256-bit output; PBEKeySpec password is cleared. [TransferCodec.kt:75-82]
- Default iterations = 600000. [TransferCodec.kt:86]
- The pepper literal exists in source at TransferCodec.kt:93. Its value is deliberately not reproduced. Source comment describes it as an accidental-decryption barrier, not the main secret. [TransferCodec.kt:23-27]
- Wrong passphrase, tampering, truncation, and empty data are indistinguishable as TransferDecodeResult.Failed. [TransferCodec.kt:13-20,48-73]
- Unsupported version maps to TransferDecodeResult.Unsupported. [TransferCodec.kt:63-65]

9.2 Plaintext layout

IMPLEMENTED — VERIFIED IN SOURCE

- VERSION = 2; maximum field length 4096 bytes. [data/transfer/TransferSerializer.kt:19-20]
- Header: version byte, int64 createdAtMillis, account-count byte. [TransferSerializer.kt:22-29]
- Account count must be 1..32. [TransferSerializer.kt:34-39; domain/transfer/TransferPackage.kt:36-46]
- Per-account order: emailAddress, displayName, colorArgb, IMAP endpoint, SMTP endpoint, IMAP password, SMTP password. [TransferSerializer.kt:50-69]
- Endpoint order: host text, port int, security enum name, authMethod enum name, username text. [TransferSerializer.kt:89-95,117-123]
- Text fields are UTF-8 byte blocks with big-endian int length via Java DataOutputStream/DataInputStream. [TransferSerializer.kt:9-14,71-103]
- Permitted enum names are SSL_TLS/STARTTLS for ConnectionSecurity and NORMAL_PASSWORD for AuthMethod. [domain/model/ServerEndpoint.kt:3-6]
- Oversized or negative field lengths are rejected. [TransferSerializer.kt:97-100]
- Password byte and char buffers are zeroed; partially read accounts are wiped on parse failure. [TransferSerializer.kt:41-46,78-86,105-114]
